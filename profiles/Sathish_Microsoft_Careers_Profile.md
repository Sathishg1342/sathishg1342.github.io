# Microsoft Careers Profile — Updated Content

Microsoft's portal (careers.microsoft.com) is an enterprise ATS, not a consumer job board like Naukri — it
doesn't publish granular per-field character limits. Constraints below are the ones actually confirmed via
Microsoft's own help documentation; where a limit isn't publicly stated, that's flagged explicitly rather than
guessed.

---

## Confirmed constraints

- **Resume file size: 1 MB max.** Your current `Sathish_Resume_ATS.pdf` is well under this — no action needed.
- Sign-in via personal email **or LinkedIn credentials** — using LinkedIn login can pre-fill some profile fields.
- Resume is **auto-parsed** into: contact info, skills, work experience, education, certifications. You must
  **manually review and correct** the parsed fields — parsing frequently misses nuance (e.g. it may flatten
  "LangChain, LangGraph" or miss project-level detail).
- No published character limits on individual text fields (profile summary, experience descriptions) — treat
  resume-length content as safe; don't pad indefinitely.
- Each job application includes **job-specific screening questions** (required qualifications confirmation,
  sometimes preferred qualifications) — answered per application, not part of the standing profile.
- Voluntary self-identification (gender, veteran/disability status, ethnicity) — optional, US-centric; may not
  apply for India-based roles.

## Practical notes

1. **Microsoft's portal has no keyword-ranked search like Naukri** — your resume content matters more than any
   profile field wording. Keep `Sathish_Resume_ATS.pdf` as your primary lever; these profile fields are secondary.
2. **A referral changes outcomes more at Microsoft than at most companies** — if you know anyone there, use the
   internal referral program before cold-applying.
3. No published application-frequency cap, but avoid mass-applying to near-duplicate roles in a short window —
   recruiters can see this and it reads poorly.
